## What is Rhinon?

Rhinon is a unified platform that gives product and engineering teams a single place to
build internal tools, automate workflows and ship customer‑facing features. It pairs a
fast, typed API with a flexible UI layer so you can move from prototype to production
without rewriting your stack.

- **Composable** — every primitive is an API, and every API is documented here.
- **Typed end‑to‑end** — first‑class SDKs for TypeScript, Python and Go.
- **Secure by default** — scoped tokens, audit logs and SSO out of the box.
